# BulandTech Website

**bulandtech.in** — the website of BulandTech, a digital studio from Bugrasi Road, Syana, Bulandshahr (UP) for website development, app development, graphic design, video editing, web design, digital marketing and music production.

Static website — plain HTML, CSS and JavaScript. No framework, no build step needed to host it.

> **New here?** Read [QUICK-SETUP.md](QUICK-SETUP.md) for how to run, update and publish the site.

---

## Features

**Design**
- Light, animated design with an orange brand gradient
- 5-second orange splash screen with the BulandTech logo and floating white icons (shown on first visit; 0.7 s on later pages)
- Scroll reveal, floating images, card glow, animated headings, scroll progress bar
- Respects "reduce motion" settings on phones and computers

**Phone & tablet (app-like)**
- Bottom tab bar: Home · Services · Work · Help · Contact
- Swipeable card rows with page dots (services, pricing, process and more)
- Floating **Call** and **WhatsApp** buttons
- Installable — "Add to Home Screen" uses the BulandTech logo (`manifest.webmanifest`)

**Portfolio (real work only)**
- 28 graphic designs with category filters and a full-screen lightbox
- 3 wedding films + 1 YouTube music edit
- 7 apps live on Google Play

**Forms** — both send email to **support@bulandtech.in** through [FormSubmit](https://formsubmit.co)
- Contact form (home page)
- Review form with star rating and publish permission (`submit-review.html`)

**SEO**
- Keyword titles, descriptions and H1 on every page (Bulandshahr, Syana, Noida, Delhi NCR)
- Schema.org structured data: LocalBusiness, Service, FAQPage, BreadcrumbList, WebSite
- Service FAQ and "Service areas" sections
- `sitemap.xml` (13 pages), `robots.txt`, canonical, Open Graph and Twitter tags

## Folder structure

```
bulandtecg-main/
├── *.html                  13 pages (generated — see "Editing" below)
├── styles.css              all styles
├── script.js               all behaviour (no libraries)
├── manifest.webmanifest    "Add to Home Screen" settings
├── sitemap.xml, robots.txt SEO files (generated)
├── CNAME                   custom domain for GitHub Pages: bulandtech.in
├── netlify.toml            Netlify hosting settings (keeps _tools and docs off the live site)
├── LICENSE                 All rights reserved — copying not allowed
├── media/                  compressed images, videos, logo and icons
│   ├── *.webp / *-sm.webp  portfolio designs (full size / thumbnail)
│   ├── *.mp4, *-poster.webp wedding films and their cover images
│   ├── logo-*.webp, icon-*.png, favicon-48.png, apple-touch-icon.png
│   ├── og-image.jpg        image shown when the link is shared on WhatsApp/Facebook
│   └── splash/             white icons used on the splash screen
└── _tools/                 page generator and media compressor (not published)

    ├── meta.json           old SEO text kept for reference
    └── compress.py         converts images to WebP and compresses videos
```

## Editing

All 13 pages share the same header, footer, tab bar and buttons. They are generated by `_tools/build.py`, so a change made there updates every page at once.

```bash
python _tools/build.py .
```

Run it from the `bulandtecg-main` folder (Python 3.8+, no extra packages needed).

- **Text, prices, services, portfolio, FAQ, SEO** → edit `_tools/build.py`, then run the command above.
- **Colours, spacing, animations** → edit `styles.css` (colours are at the top under `:root`).
- **Behaviour** (splash time, forms, sliders) → edit `script.js`.

> If you edit an `.html` file by hand, the next run of `build.py` will overwrite it. Put permanent changes in `build.py`.

Common edits are explained step by step in [QUICK-SETUP.md](QUICK-SETUP.md).
